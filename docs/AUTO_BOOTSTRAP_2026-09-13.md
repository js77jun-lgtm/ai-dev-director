# 프로젝트 자동 준비 — 2026-09-13

`bootstrap.enabled: true`로 프로젝트 선택/실행 시 다음을 자동 처리한다.

- 지정한 프로젝트 디렉터리가 없으면 생성한다. 드라이브 루트, 홈, Director 제어 저장소와 상위 경로는 거부한다.
- Git이 없으면 초기화하고, HEAD가 없으면 빈 시작 커밋을 만든다. 사용자 파일을 초기 커밋에 넣지 않는다.
- 현재 작업 중인 소스와 미추적 소스/테스트를 별도 Git 인덱스로 스냅샷한다. 사용자 HEAD와 실제 인덱스는 변경하지 않는다.
- 미추적 데이터, 가상환경, 의존성, 비밀정보 이름의 파일은 스냅샷에서 제외한다. 이는 임의 파일 내용에 대한 비밀정보 탐지기는 아니다.
- 기존 `.venv`의 Python을 기본 pytest 명령에 사용한다. 의존성을 임의 설치하지 않는다.
- 빈/Python 프로젝트에 테스트가 전혀 없으면 격리 작업트리에 구문 검사 테스트를 만든다. 이 테스트만으로 제품 구현을 PASS시키지 않는다. 실제 동작 테스트를 추가해야 한다.
- 기존 테스트 실패, 경로 이탈, 리뷰 결함은 숨기거나 승인으로 우회하지 않는다.
- Builder 프롬프트에 Order.context를 전달한다. 맥락 정보는 쓰기 범위나 권한을 확장하지 않는다. 기존 누락으로 상세 구현 계약이 전달되지 않았던 문제를 수정하고 회귀 테스트를 추가했다.

작업트리는 현재 작업본의 비공개 스냅샷에서 시작하므로 원본 HEAD와 다를 수 있다. 원본 반영의 기존 충돌/dirty 보호는 유지된다. PASS는 격리 작업트리에서 검증된 결과이며 원본 반영 완료를 뜻하지 않는다.
