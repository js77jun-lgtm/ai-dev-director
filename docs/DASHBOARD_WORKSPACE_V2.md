# AI DEV 작업실 화면 개편

2026-09-14. 기본 주소: http://127.0.0.1:8081/

실행 중인 서버 재시작 없이 console/의 정적 파일만 교체했다. /classic은 원본 화면으로 보존한다. 새 기본 화면은 같은 출처의 기존 대시보드를 iframe에 표시하고 실제 DOM에 새 배치, 스타일, 읽기 전용 상태 관제 영역과 대화 도구를 추가한다. 별도 엔진이나 별도 대화 세션을 생성하지 않는다.

## 변경

- 현재 작업, 다음 행동, 프로젝트, 최근 단계 기록과 5단계 진행 표시.
- 준비 오류/검증 실패를 일반적인 사용자 승인 문구보다 구체적으로 표시.
- 세 CLI의 현재 역할과 담당 기능, 읽기 쉬운 대화 카드와 충분한 입력 공간.
- 알림 접기, 최신 대화 이동, NORMAL/연구 전환, 솔로몬 요청 기록 보기.
- 결과 상세 창의 배경·크기·글자와 모바일 세로 배치 수정.
- 기존 프로젝트 변경, 대화 전송, 승인, 결과 조회/적용 기능은 기존 핸들러를 사용한다.

## 확인

기존 HTTP/읽기 전용 점검 테스트 10개 통과. 실제 8081 브라우저에서 상태 표시, 알림 숨기기, 최신 대화 이동, 연구 보기 전환, 솔로몬 작업함과 결과 테스트 근거를 확인했다. 390×844에서도 대화와 입력창을 확인하고 뷰포트를 원래대로 복원했다. 테스트 중 새 개발 지시 전송이나 결과 적용은 수행하지 않았다.

화면 개편은 실행 엔진 오류 수정을 뜻하지 않는다. 확인 당시 최근 RUN-260914085901-53AD7B40B44D43DF86080E89C30A8284는 ** 경로 권한 규칙 준비 오류로 HUMAN_REQUIRED였다. 이 원인을 새 화면에 표시한다.
